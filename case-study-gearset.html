Four UX Fixes, Shipped From My CSM Role

I spend all day in Gearset's product. When I kept noticing friction that customers were reporting too, I got codebase access and shipped the fixes myself.

Context

I use the product all day. That's where these came from.

I'm in Gearset constantly for my CSM role. Customer calls, live troubleshooting, product walkthroughs. I run into the same rough edges our users run into.

So I got access to the codebase and Claude Code, learned the UX team's workflows, and started fixing things.

Fix 01

Delegate access: a save button you had to scroll for.

The delegate access page listed every user in one long column. To save changes, you scrolled past all of them. One customer had 126 users on this page. I found an existing table component from elsewhere in the platform, reused it here with pagination and a persistent save button, and raised a PR.

Before Save button hidden below all users

31 users listed in full. The Save button sits below every row.

After Scrollable table, save button always visible

126 users in a scrollable table. Save is always visible.

Fix 02

Search results you couldn't scan.

The What's New section has a search bar. You type a term, get results, but your search term isn't highlighted anywhere in those results. You end up reading each one to find the match. I added keyword highlighting so matches stand out immediately.

Before No highlighting of search terms

After Search terms highlighted in results

Fix 03

A card that looked clickable but mostly wasn't.

In the error monitoring view, the card looked like a single click target, but only part of it responded. Clicks on the dead space did nothing. I extended the clickable area to cover the full card.

Before Clickable area smaller than the card

After Entire card responds to clicks

Fix 04

A panel you could resize, if you knew to try.

The agent window was already resizable, but there was no visual signal. Users would only discover it by accident. I added a visible handle with a hover state so the interaction is discoverable.

Before No visible resize affordance

After Resize handle with hover state
